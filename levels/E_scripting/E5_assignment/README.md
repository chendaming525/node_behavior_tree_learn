# E5 - 赋值与多语句

## 本关目标

让脚本不仅能读 Blackboard，还能创建和修改变量，并连续执行多条语句。

## 赋值语义

| 运算符 | 语义 |
|--------|------|
| `:=` | 创建或覆盖变量 |
| `=` | 仅修改已存在变量 |
| `+=` 等 | 读取旧值、计算后写回 |

赋值左侧必须是变量名，`(A+1):=2` 必须在解析期失败。

## 多语句

```text
A:=1; B:=A+2; B
```

依次执行所有 AST，忽略中间值，返回最后一条表达式的值。

## 边界

要写：

- `ExprAssignment`
- Parser 中的左值检查
- `parseStatements`
- 分号处理

不要写：

- `ScriptFunction` 缓存
- 行为树节点和 XML

## 文件

| 文件 | 职责 |
|------|------|
| `assignment.hpp` | 赋值 AST 及求值 |
| `statements.hpp` | 多语句解析/执行辅助 |
| `e5_assignment.cpp` | 赋值语义测试 |

## 验收

- [ ] `A:=1; B:=A+2; B` 返回 3，且 BB 有 A、B。
- [ ] `x=1` 在 x 不存在时失败。
- [ ] `x:=1; x+=2` 后 x 为 3。
- [ ] 非变量左值在解析期报错。
- [ ] 多余分号的规则已明确并有测试。
