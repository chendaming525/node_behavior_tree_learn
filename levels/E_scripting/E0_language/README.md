# E0 - 定义脚本语言边界

## 本关目标

先写清楚 MiniBT 脚本能做什么、不能做什么。此时不写解析器。

## 边界

要定义：

- 类型：`number`、`bool`、`string`
- 变量：变量名对应 Blackboard key
- 运算：算术、比较、逻辑、三元表达式
- 赋值：`:=`、`=`、`+=`、`-=`、`*=`、`/=`
- 多语句：用 `;` 分隔，最后一条表达式作为结果

不要定义：

- 函数、循环、import
- 文件、网络、线程 API
- C++ / Python `eval`
- 自定义类和结构体语法

## 语法示例

```text
A := 42
msg := 'hello'
ok := A > 10 && ready
A += 1; B := A * 2
x > 0 ? 'pos' : 'neg'
```

4. 写出错误示例。
5. 明确宿主只能通过 `Environment` 暴露能力。
